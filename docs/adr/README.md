# Architecture Decision Records

Decisions are recorded as they are made, using the lightweight format proposed by
Michael Nygard. Each record states the context that forced the decision, the decision
itself, the alternatives that were rejected and why, and the consequences accepted.

Status values: `proposed` -> `accepted` -> `deprecated` | `superseded by ADR-NNNN`.
